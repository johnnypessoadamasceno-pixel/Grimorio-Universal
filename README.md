# Grimório Universal

**Grimório de RPG para D&D 2024 e Tormenta20**

O site completo está neste repositório. O conteúdo foi dividido em 11 arquivos em `pacote/` para contornar o limite de envio do conector. A página `index.html` carrega e reconstrói o Grimório, incluindo as imagens.

## Publicar grátis (uma única configuração)

1. Entre em **Settings → Pages**: https://github.com/johnnypessoadamasceno-pixel/Grimorio-Universal/settings/pages
2. Em **Build and deployment**, selecione **Deploy from a branch**.
3. Escolha **Branch: main**, pasta **/(root)** e clique em **Save**.
4. Aguarde o GitHub indicar que a publicação terminou. O endereço padrão será:
   https://johnnypessoadamasceno-pixel.github.io/Grimorio-Universal/

O site foi configurado para solicitar que buscadores não o indexem, mas **é público para quem descobrir o endereço**. Não há autenticação real: para restringir a convidados específicos é preciso um provedor com controle de acesso, como Cloudflare Access, configurado separadamente.

### Aviso
Projeto de fãs independente para uso em mesas de RPG. Não associado oficialmente às editoras de D&D e Tormenta20. Compartilhe respeitando os direitos autorais.

Para atualizar a experiência, substitua os arquivos de `pacote/` e `index.html` preservando os caminhos.
